# AGENTS.md

Instructions for AI agents and contributors working on this repository.

This file is the top-level index. The detailed repository rules are grouped by
topic in the `agent-rules/` directory. Every referenced file is a mandatory part
of these instructions and applies repository-wide unless a more specific
`AGENTS.md` overrides it.

## 1. Language

Use English for code comments, commit messages, branch names, identifiers, and
documentation unless there is a strong reason not to.

@agent-rules/language.md

## 2. Naming Conventions

Use lowercase kebab-case for directories and non-source files. Use PascalCase
for C# source files, snake_case for other source files, and standard C# naming
conventions inside C# source code.

@agent-rules/naming-conventions.md

## 3. Git Rules

Work on a dedicated branch, keep each commit focused, follow the branch and
commit naming formats, and verify the project before pushing.

@agent-rules/git-rules.md
